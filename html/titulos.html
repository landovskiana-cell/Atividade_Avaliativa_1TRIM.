explicao

As tags h1 até h6 no HTML servem para criar títulos e subtítulos em diferentes níveis de importância, tamanhos. O h1 é o título mais importante, o h2 é um subtítulo do h1, o h3 é um subtítulo do h2, e assim por diante, até o h6, que é o menos importante. A cada numero maior, o assunto de dentro aparece em fontes menores.
